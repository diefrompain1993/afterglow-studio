Твоя маленькая студия.

Загрузи аудио, выбери пресет и нажми «Послушать с эффектами». Экспорт сохраняет ремикс в библиотеку, откуда можно скачать файл.

MP3, WAV и другие форматы, которые декодирует браузер. Большие треки требуют свободной памяти. Для стабильности: до 20 минут и 150 МБ на файл.

Прямые ссылки работают, если сервер разрешает CORS. YouTube и SoundCloud импортируются в локальной версии через сервер. На GitHub Pages открой локальную студию для такого импорта, затем загрузи полученный файл сюда.
