# Afterglow Studio

Русскоязычная студия slowed + reverb без подписок. Независимая реализация, не связанная с slowedandreverb.studio.

## Возможности

- Множественная загрузка файлов и drag & drop.
- Скорость и высота тона отдельно, реверберация со свёрткой, бас.
- Slowed + Reverb, Nightcore, Daycore, чистый звук.
- Обрезка, fade in/out, пиковая нормализация.
- Прослушивание обработанного трека, перемотка, повтор, громкость.
- MP3 320 kbps и WAV 16 bit, 44.1 kHz stereo.
- Пакетная обработка отмеченных треков, библиотека IndexedDB, свои настройки по умолчанию, светлая и тёмная темы.
- Демо синтезируется приложением, сторонние треки в репозитории отсутствуют.

## GitHub Pages

Публикуется только папка `public`. Эффекты, кодирование и библиотека работают в браузере. Прямые аудиоссылки поддерживаются при разрешённом CORS. YouTube и SoundCloud требуют сервер; Pages не может выполнять yt-dlp. Библиотека изолирована по устройству/браузеру/адресу сайта. Ограничение браузерной версии: 150 МБ и 20 минут на трек. При малом объёме памяти лучше использовать короткие треки.

Обработка скорости/тона и MP3 вынесена в Worker. Остальные эффекты рендерятся через OfflineAudioContext. Предпрослушивание пересчитывается по кнопке; настройки не применяются мгновенно к уже запущенному воспроизведению. Экспорт всегда использует текущие настройки. Пакетный экспорт обрабатывает полные отмеченные треки с текущими эффектами и сохраняет результаты в библиотеке.

## Локальная версия с импортом ссылок

Нужны Python 3.10+, Node.js (для YouTube) и интернет. На Windows запустите `Start.cmd`. Либо:

```sh
python -m pip install -r requirements.txt
python server.py
```

Открыть http://127.0.0.1:8765. Сервер слушает только loopback. yt-dlp импортирует отдельные публично доступные треки YouTube, SoundCloud и других поддерживаемых сайтов. Нет обхода DRM, авторизации или платного доступа; аккаунты/cookies не используются. Сервисы могут блокировать загрузку или требовать обновления yt-dlp. Используйте материалы, которые вам разрешено скачивать и обрабатывать. Импортированные WAV остаются локально в `data/`; эта папка не публикуется.

Для обновления загрузчика: `python -m pip install -U "yt-dlp[default]"`.

## Зависимости

- SoundTouchJS 0.3.0: https://github.com/cutterbl/SoundTouchJS — LGPL-2.1; неизменённый модуль и полный текст лицензии в public/vendor.
- lamejs 1.2.1: https://github.com/zhuker/lamejs — LGPL-3.0; неизменённый bundle и лицензия в public/vendor.
- FFmpeg через imageio-ffmpeg и yt-dlp используются только локальным сервером, не входят в Pages.

Никакой аналитики и рекламы. Шрифт Manrope загружается с Google Fonts; при отсутствии сети используется системный шрифт.
