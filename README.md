# Afterglow Studio

Русскоязычная студия slowed + reverb без подписок. Независимая реализация, не связанная с slowedandreverb.studio.

## Возможности

- Множественная загрузка файлов и drag & drop.
- Скорость и высота тона отдельно, реверберация со свёрткой, бас.
- Slowed + Reverb, Nightcore, Daycore, чистый звук.
- Обрезка, fade in/out, пиковая нормализация.
- Прослушивание обработанного трека, перемотка, повтор, громкость.
- MP3 320 kbps и WAV 16 bit, 44.1 kHz stereo.
- Пакетная обработка отмеченных треков, библиотека IndexedDB, свои настройки по умолчанию, светлая и тёмная темы.
- Демо синтезируется приложением, сторонние треки в репозитории отсутствуют.

## GitHub Pages

Публикуется только папка `public`. Эффекты, кодирование и библиотека работают в браузере. Прямые аудиоссылки поддерживаются при разрешённом CORS. YouTube и SoundCloud требуют сервер; Pages не может выполнять yt-dlp. Библиотека изолирована по устройству/браузеру/адресу сайта. Ограничение браузерной версии: 150 МБ и 20 минут на трек. При малом объёме памяти лучше использовать короткие треки.

Основной режим использует нативный AudioBufferSourceNode.playbackRate: скорость и высота тона связаны, как у пластинки. Это убирает артефакты растяжения на 0.25× и соответствует основному принципу референса. Независимая высота тона включается переключателем и работает через SoundTouch AudioWorklet; на экстремальном растяжении у этого режима возможны артефакты. Реверберация использует стереоимпульс с экспоненциальным затуханием и равномощное смешивание wet/dry, бас — разделение частотных полос. Предпрослушивание и экспорт используют общие настройки фильтров. Полной идентичности звучания всех режимов референсу не заявляется.

Перемотка работает перетаскиванием мышью/пальцем с захватом указателя и с клавиатуры. На мобильном видны четыре из двенадцати пресетов; остальные раскрываются отдельной кнопкой. Шрифты Unbounded, Golos Text и IBM Plex Mono включены локально вместе с SIL OFL, внешней загрузки шрифтов нет.

Экспорт скорости/тона и MP3 вынесен в Worker, остальные эффекты рендерятся через OfflineAudioContext. Экспорт использует текущие настройки. Пакетный экспорт обрабатывает полные отмеченные треки с текущими эффектами и сохраняет результаты в библиотеке. Проверка DSP: `node test-live.mjs` (тональность, темп, изменение параметров без сброса позиции, пауза, перемотка, обрезка, повтор и окончание).

## Локальная версия с импортом ссылок

Нужны Python 3.10+, Node.js (для YouTube) и интернет. На Windows запустите `Start.cmd`. Либо:

```sh
python -m pip install -r requirements.txt
python server.py
```

Открыть http://127.0.0.1:8765. Сервер слушает только loopback. yt-dlp импортирует отдельные публично доступные треки YouTube, SoundCloud и других поддерживаемых сайтов. Нет обхода DRM, авторизации или платного доступа; аккаунты/cookies не используются. Сервисы могут блокировать загрузку или требовать обновления yt-dlp. Используйте материалы, которые вам разрешено скачивать и обрабатывать. Импортированные WAV остаются локально в `data/`; эта папка не публикуется.

Для обновления загрузчика: `python -m pip install -U "yt-dlp[default]"`.

## Зависимости

- SoundTouchJS 0.3.0: https://github.com/cutterbl/SoundTouchJS — LGPL-2.1; неизменённый модуль и полный текст лицензии в public/vendor.
- lamejs 1.2.1: https://github.com/zhuker/lamejs — LGPL-3.0; неизменённый bundle и лицензия в public/vendor.
- FFmpeg через imageio-ffmpeg и yt-dlp используются только локальным сервером, не входят в Pages.

Никакой аналитики и рекламы. Исходники шрифтов: https://github.com/google/fonts (ofl/unbounded, ofl/golostext, ofl/ibmplexmono).

## Облачный импорт для iPhone

Сервер Railway: https://afterglow-import-production.up.railway.app
Адрес уже задан в `public/config.json`: на GitHub Pages достаточно вставить публичную ссылку YouTube/SoundCloud. Локальный сервер не нужен. Пользовательский адрес в справке имеет приоритет над конфигурацией сайта.

Сервис собирается из корневого `Dockerfile`, запускает `cloud.py` через Uvicorn на `$PORT`, проверка готовности — `/api/health`. Разрешённый CORS origin по умолчанию: `https://diefrompain1993.github.io`; для другой копии задайте `ALLOWED_ORIGIN`. Диски и базы данных не нужны. Включайте Serverless, чтобы сервер засыпал без работы. После пробного периода Railway нужно выбрать Free; бесплатные квоты и ограничения описаны на https://docs.railway.com/pricing/free-plan . Платный тариф для проекта не требуется.

Один процесс загрузки, максимум две активные/ожидающие задачи и 12 импортов в час на экземпляр. Треки до 20 минут, до 80 МБ на загрузку, выходной MP3 до 40 МБ. MP3 192 kbps не улучшает качество исходника. Временные файлы очищаются через 30 минут при последующих запросах или при перезапуске. Библиотека хранится на устройстве в браузере.

Нужны публичные отдельные ссылки; без cookies, авторизации, обхода DRM или платного доступа. Площадки могут блокировать облачные IP, поэтому работа каждой ссылки не гарантируется.

API-тесты: установить `cloud-requirements.txt` и `httpx`, выполнить `python test-cloud.py`. Аудиодвижок: `node test-native.mjs`, `node test-live.mjs`. `render.yaml` сохранён как альтернативный способ размещения; Render может требовать карту даже для Free.

## Версия 7: old web + живое фоновое аудио

Вместо отдельной подготовки микса при обычном ▶ запрашивается navigator.audioSession.type = playback. Цепочка Web Audio не меняется при блокировке, рендер и скрытый аудиофайл не используются. Media Session управляет тем же живым транспортом: play/pause, stop, seek, шкала времени с учётом скорости и обрезки. Некоторые версии iOS приостанавливают Web Audio вопреки аудиорежиму. Проверка реальной блокировки iPhone ещё нужна. Для таких устройств остаётся скачивание микса со всеми эффектами. Основание: https://bugs.webkit.org/show_bug.cgi?id=237322#c6 ; ограничения: https://bugs.webkit.org/show_bug.cgi?id=276016 . Старый background-player.js сохранён как неиспользуемый модуль версии 6.

Новый дизайн: графит, бледно-зелёный CRT, пиксельные заголовки, прямоугольные панели, GIF-штампы. Локальные бесплатные шрифты Press Start 2P и PT Mono из google/fonts, лицензии SIL OFL в public/fonts. 12 оригинальных GIF в public/stamps нарисованы для Afterglow. Steam, Portal и Half-Life — отсылки к играм и сервису, не заявление о партнёрстве. Генератор: scripts/make-stamps.py (Pillow). GIF OFF и prefers-reduced-motion заменяют GIF статичными PNG.

Визуальные ориентиры, просмотрены 28 октября 2026:
- https://catlivinginwires.com/ — исходный референс: графитовый фон, полка штампов, пиксельные подписи.
- https://fauux.neocities.org/ — тёмный wired-стиль, текстовые символы, музыкальная атмосфера.
- https://cinni.net/ — личная коллекция, рамки, декоративные web goodies.
- https://sadgrl.online/ — тёмная личная страница, выразительная типографика.
- https://dokode.moe/ — игровые и аниме-детали, декоративные значки и пиксельные текстуры.
- https://omnipresence.neocities.org/ — монохромный пиксельный рисунок и тёмный фон.

Проверки: node test-media-session.mjs; node test-native.mjs; node test-live.mjs. Проверена компоновка 390px в iframe, не эмуляция настоящего iOS.
