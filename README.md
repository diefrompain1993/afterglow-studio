# Afterglow Studio

Русскоязычная студия slowed + reverb без подписок. Независимая реализация, не связанная с slowedandreverb.studio.

## Возможности

- Множественная загрузка файлов и drag & drop.
- Скорость и высота тона отдельно, реверберация со свёрткой, бас.
- Slowed + Reverb, Nightcore, Daycore, чистый звук.
- Обрезка, fade in/out, пиковая нормализация.
- Прослушивание обработанного трека, перемотка, повтор, громкость.
- MP3 320 kbps и WAV 16 bit, 44.1 kHz stereo.
- Пакетная обработка отмеченных треков, библиотека IndexedDB, свои настройки по умолчанию, светлая и тёмная темы.
- Демо синтезируется приложением, сторонние треки в репозитории отсутствуют.

## GitHub Pages

Публикуется только папка `public`. Эффекты, кодирование и библиотека работают в браузере. Прямые аудиоссылки поддерживаются при разрешённом CORS. YouTube и SoundCloud требуют сервер; Pages не может выполнять yt-dlp. Библиотека изолирована по устройству/браузеру/адресу сайта. Ограничение браузерной версии: 150 МБ и 20 минут на трек. При малом объёме памяти лучше использовать короткие треки.

Основной режим использует нативный AudioBufferSourceNode.playbackRate: скорость и высота тона связаны, как у пластинки. Это убирает артефакты растяжения на 0.25× и соответствует основному принципу референса. Независимая высота тона включается переключателем и работает через SoundTouch AudioWorklet; на экстремальном растяжении у этого режима возможны артефакты. Реверберация использует стереоимпульс с экспоненциальным затуханием и равномощное смешивание wet/dry, бас — разделение частотных полос. Предпрослушивание и экспорт используют общие настройки фильтров. Полной идентичности звучания всех режимов референсу не заявляется.

Перемотка работает перетаскиванием мышью/пальцем с захватом указателя и с клавиатуры. На мобильном видны четыре из двенадцати пресетов; остальные раскрываются отдельной кнопкой. Шрифты Unbounded, Golos Text и IBM Plex Mono включены локально вместе с SIL OFL, внешней загрузки шрифтов нет.

Экспорт скорости/тона и MP3 вынесен в Worker, остальные эффекты рендерятся через OfflineAudioContext. Экспорт использует текущие настройки. Пакетный экспорт обрабатывает полные отмеченные треки с текущими эффектами и сохраняет результаты в библиотеке. Проверка DSP: `node test-live.mjs` (тональность, темп, изменение параметров без сброса позиции, пауза, перемотка, обрезка, повтор и окончание).

## Локальная версия с импортом ссылок

Нужны Python 3.10+, Node.js (для YouTube) и интернет. На Windows запустите `Start.cmd`. Либо:

```sh
python -m pip install -r requirements.txt
python server.py
```

Открыть http://127.0.0.1:8765. Сервер слушает только loopback. yt-dlp импортирует отдельные публично доступные треки YouTube, SoundCloud и других поддерживаемых сайтов. Нет обхода DRM, авторизации или платного доступа; аккаунты/cookies не используются. Сервисы могут блокировать загрузку или требовать обновления yt-dlp. Используйте материалы, которые вам разрешено скачивать и обрабатывать. Импортированные WAV остаются локально в `data/`; эта папка не публикуется.

Для обновления загрузчика: `python -m pip install -U "yt-dlp[default]"`.

## Зависимости

- SoundTouchJS 0.3.0: https://github.com/cutterbl/SoundTouchJS — LGPL-2.1; неизменённый модуль и полный текст лицензии в public/vendor.
- lamejs 1.2.1: https://github.com/zhuker/lamejs — LGPL-3.0; неизменённый bundle и лицензия в public/vendor.
- FFmpeg через imageio-ffmpeg и yt-dlp используются только локальным сервером, не входят в Pages.

Никакой аналитики и рекламы. Исходники шрифтов: https://github.com/google/fonts (ofl/unbounded, ofl/golostext, ofl/ibmplexmono).

## Бесплатный облачный импорт для iPhone

В репозитории есть отдельный `cloud.py` (FastAPI), `Dockerfile` и `render.yaml` с явным `plan: free`. Это подготовленная конфигурация, а не уже размещённый сервер.

1. Открой https://render.com/deploy?repo=https://github.com/diefrompain1993/afterglow-studio и войди/зарегистрируйся в своём Render.
2. Создай Blueprint из этого репозитория. Проверь тариф **Free**, не переключайся на платный тариф. Для тестирования не добавляй платные базы и диски.
3. После запуска открой выданный HTTPS-адрес сервиса. На нём размещена та же студия с работающим серверным маршрутом импорта.
4. Для импорта на GitHub Pages открой справку (?) и один раз укажи этот адрес. Либо владелец может записать его в `public/config.json` → `importApi` и опубликовать: тогда пользователям ничего настраивать не понадобится.

Нужны только публичные отдельные ссылки YouTube/SoundCloud. Нет авторизации в этих сервисах, cookies, обхода DRM или платного доступа. Cloud IP могут блокироваться площадками: отсутствие гарантии работы каждой ссылки — ограничение загрузчика и сервиса.

Free Render засыпает после 15 минут простоя и может запускаться около минуты. Бесплатный ресурс ограничен 750 часами в месяц на workspace и другими квотами провайдера. У сервера один процесс загрузки и очередь до двух задач, не более 12 запросов в час на экземпляр, треки до 20 минут и 80 МБ на скачивание. Он отдаёт MP3 192 kbps (повышение битрейта исходника не улучшает его качество), временные файлы удаляются через 30 минут при последующих запросах и при перезапуске. Долговременная библиотека остаётся в браузере.

Проверки: `node test-native.mjs`, `node test-live.mjs`. Для API: установить `cloud-requirements.txt` и `httpx`, выполнить `python test-cloud.py`. Docker требует Docker runtime; конфигурация здесь не проверена запуском контейнера на Render до подключения аккаунта.

Фоновое прослушивание на iPhone: настрой эффекты → «Слушать с выключенным экраном» → дождись готовности → нажми ▶ → заблокируй экран. Рекомендуется обычная вкладка Safari. Рендер включает скорость, тон, бас, реверберацию, обрезку, переходы и выбранную нормализацию, затем кодируется в MP3 320 kbps и играет через HTMLAudioElement напрямую, без Web Audio. Есть Media Session для управления с экрана блокировки. Изменение эффектов возвращает живой режим; фоновый микс нужно подготовить заново. Вкладку нельзя закрывать. Поведение при блокировке требует проверки на реальном iPhone; выгрузка вкладки системой прервёт воспроизведение.
